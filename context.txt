== 1. PROJECT SNAPSHOT ==
PRAMANAM is an online verification system for weighing & measuring
instruments under the Legal Metrology framework. Traders apply online,
LMO/GATC officers schedule and perform field inspections, certificates
are issued as signed QR payloads (Ed25519 + JWS) with public badge
verification, plus an offline sticker-parse mode. The app is a Next.js
14 (app router) full-stack monolith backed by Postgres/Prisma, Redis/
BullMQ jobs, and MinIO object storage. All API routes and UI pages are
currently K0 scaffolding (turn-key mock stubs against packages/shared).

== 2. TECH STACK ==
- Next.js 14 (app router, TypeScript, Tailwind, ESLint)
- PostgreSQL / Prisma ORM (v6 pinned, prisma-client-js generator)
- Redis / BullMQ (queues) + ioredis
- MinIO (S3-compatible object store; @aws-sdk/client-s3)
- node:crypto Ed25519 for signature / JWS / QR certificate payloads
- jose (JWT), qrcode, pdf-lib, vitest, tsx

== 3. REPO MAP ==
